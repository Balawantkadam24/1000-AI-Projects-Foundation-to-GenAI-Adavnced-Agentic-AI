# Exporting the complete 1,000-project catalogue

`My Project.html` is a standalone browser application and generates exactly 1,000 projects from its section definitions:

- Foundation: 120
- Beginner: 150
- Intermediate: 180
- Advanced: 150
- Expert: 100
- Cutting-Edge Research: 60
- GenAI Advanced: 120
- Agentic Advanced: 120

## Images

Open `My Project.html`, choose **Show all 1000** (or choose a section), then use **Full Page Image** or the camera button on a section. The generated PNG includes the creator credit and the current filters.

## PDFs

Use the **PDF** button and choose **Save as PDF** in the browser print dialog. For the complete catalogue, select **Show all 1000** first and clear all filters. For a section PDF, select its level/stat card before printing.

This browser-side approach avoids storing large, stale binary files in Git and means every PDF is generated from the current catalogue data.
